# Smart Academic Attendance and Internal Performance Monitoring System

## Project Overview

The Smart Academic Attendance and Internal Performance Monitoring System is a web-based application designed to help educational institutions monitor student attendance and academic performance effectively.

The system introduces an Academic Attendance Index (AAI), which combines attendance percentage and internal assessment performance to evaluate a student's overall academic standing.

## Features

* Student Management
* Attendance Tracking
* Internal Marks Management
* Academic Attendance Index (AAI) Calculator
* Student Performance Dashboard
* Academic Risk Identification
* User-Friendly Interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Academic Attendance Index (AAI)

The Academic Attendance Index is calculated using:

AAI = (Attendance × 65%) + (Internal Performance × 35%)

This helps identify students who may require additional academic support.

## Modules

### Dashboard

Displays student statistics, attendance insights, and performance indicators.

### Students Management

Maintains student information and records.

### Attendance Management

Tracks attendance and calculates attendance percentage.

### Internal Marks Management

Stores and monitors internal examination performance.

### AAI Calculator

Calculates the Academic Attendance Index and classifies student performance.
